    Ebenen im dreidimensionalen Raum¶

    Parameterform einer Ebene¶

    Die Parameterform einer Ebene lautet:

    \[ E:\ \overrightarrow{x} = \overrightarrow{a} + t \cdot \overrightarrow{u} + s \cdot \overrightarrow{v}, \quad s,t \in \mathbb{R}. \]

    Dabei gilt:

    • \(\overrightarrow{a}=\overrightarrow{OA}\) ist der Stützvektor der Ebene,
    • \(\overrightarrow{u}\) und \(\overrightarrow{v}\) sind Spannvektoren der Ebene, \(\overrightarrow{v}\notparallel \overrightarrow{u},\ \overrightarrow{v},\overrightarrow{u}\neq \overrightarrow{0}\),
    • \(\overrightarrow{x}=\overrightarrow{OX}\) ist der Ortsvektor eines beliebigen Punktes der Ebene.

    Normalenform einer Ebene¶

    Eine Ebene kann auch durch einen Punkt und einen Normalenvektor (einen Vektor, der senkrecht auf der Ebene steht) beschrieben werden.

    Ist der Stützpunkt

    \[ P(p_1|p_2|p_3) \]

    und ein Normalenvektor \(\overrightarrow{n}\) gegeben, so lautet die Normalenform:

    \[ E:\ (\overrightarrow{x}-\overrightarrow{p}) \cdot \overrightarrow{n} = 0. \]

    Bestimmung eines Normalenvektors¶

    Sind statt eines Normalenvektors zwei Spannvektoren \(\overrightarrow{u}\) und \(\overrightarrow{v}\) gegeben, so kann der Normalenvektor auf zwei Arten bestimmt werden:

    • Skalarprodukt

    Bestimme \(\overrightarrow{n}\) durch Lösen der Gleichungen

    [ \overrightarrow{n}\cdot\overrightarrow{u}=0 \quad\text{und}\quad \overrightarrow{n}\cdot\overrightarrow{v}=0. ]

    • Kreuzprodukt

    [ \overrightarrow{n}=\overrightarrow{u}\times\overrightarrow{v}. ]

    Koordinatenform einer Ebene¶

    Eine Ebene kann auch durch eine lineare Gleichung beschrieben werden. Die Koordinatenform lautet:

    \[ E:\ a x + b y + c z = d. \]

    Dabei gilt:

    • \((a,b,c)\) sind die Koordinaten eines Normalenvektors \(\overrightarrow{n}\),
    • \(d\) ist eine reelle Zahl, die durch Einsetzen eines Punktes der Ebene bestimmt wird.

    Umwandlung der Darstellungsformen¶

    Parameterform → Normalenform¶

    Gegeben:

    \[ E:\ \overrightarrow{x} = \overrightarrow{a} + t\overrightarrow{u} + s\overrightarrow{v} \]

    Vorgehen:

    • Stützvektor: \(\overrightarrow{p}=\overrightarrow{a}\)
    • Normalenvektor:

    [ \overrightarrow{n}=\overrightarrow{u}\times\overrightarrow{v} \quad\text{oder durch}\quad \overrightarrow{n}\cdot\overrightarrow{u}=0,\ \overrightarrow{n}\cdot\overrightarrow{v}=0 ]

    Ergebnis:

    \[ E:\ (\overrightarrow{x}-\overrightarrow{p})\cdot\overrightarrow{n}=0. \]

    Parameterform → Koordinatenform¶

    Gegeben:

    \[ E:\ \overrightarrow{x} = \overrightarrow{a} + t\overrightarrow{u} + s\overrightarrow{v} \]

    Vorgehen:

    • Bestimme einen Normalenvektor \(\overrightarrow{n}\),
    • setze einen Punkt der Ebene (z. B. \(\overrightarrow{a}\)) ein,
    • löse nach \(d\) auf.

    Ergebnis:

    \[ E:\ a x + b y + c z = d. \]

    Normalenform → Parameterform¶

    Gegeben:

    \[ E:\ (\overrightarrow{x}-\overrightarrow{p})\cdot\overrightarrow{n}=0 \]

    Vorgehen:

    • Stützvektor: \(\overrightarrow{a}=\overrightarrow{p}\)
    • Bestimme zwei Spannvektoren \(\overrightarrow{u},\overrightarrow{v}\) mit

    [ \overrightarrow{n}\cdot\overrightarrow{u}=0,\quad \overrightarrow{n}\cdot\overrightarrow{v}=0 ]

    oder wähle zwei weitere Punkte der Ebene und bilde Verbindungsvektoren.

    Normalenform → Koordinatenform¶

    Gegeben:

    \[ E:\ (\overrightarrow{x}-\overrightarrow{p})\cdot\overrightarrow{n}=0 \]

    Vorgehen:

    • Multipliziere aus,
    • fasse zusammen,
    • bringe die Gleichung auf die Form

    [ a x + b y + c z = d. ]

    Koordinatenform → Parameterform¶

    Gegeben:

    \[ E:\ a x + b y + c z = d \]

    Vorgehen:

    • Bestimme einen Punkt der Ebene als Stützvektor \(\overrightarrow{a}\),
    • wähle zwei weitere Punkte der Ebene,
    • bilde aus den Verbindungsvektoren zwei Spannvektoren.

    Koordinatenform → Normalenform¶

    Gegeben:

    \[ E:\ a x + b y + c z = d \]

    Vorgehen:

    • Normalenvektor:

    [ \overrightarrow{n}=\begin{pmatrix}a\b\c\end{pmatrix} ]

    • Bestimme einen Punkt \(\overrightarrow{p}\) der Ebene.

    Ergebnis:

    \[ E:\ (\overrightarrow{x}-\overrightarrow{p})\cdot\overrightarrow{n}=0. \]
